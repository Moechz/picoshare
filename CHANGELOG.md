# Changelog

All notable user-visible changes to the PicoShare TOS application package.

## 1.5.2-1 — 2026-11-14

### Added
- First release. PicoShare (`mtlynch/picoshare:1.5.2`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8130 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/picosharedocker/`.
